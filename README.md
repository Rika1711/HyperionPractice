# Data Science Bootcamp - Coursework Repository

This repository contains the coursework completed during my Data Science Bootcamp. It showcases a variety of projects and exercises demonstrating skills in Python, SQL, and Tableau.

## Learning Objectives Demonstrated

This coursework demonstrates my understanding and application of key data science concepts and tools, including:

* **Data Wrangling and Preprocessing:** Cleaning, transforming, and preparing data for analysis.
* **Exploratory Data Analysis (EDA):** Investigating datasets to uncover patterns, insights, and anomalies.
* **Data Visualization:** Creating meaningful and informative visualizations using Python libraries and Tableau.
* **Statistical Analysis:** Applying statistical methods to analyze data and draw conclusions.
* **Machine Learning:** Building and evaluating predictive models using various algorithms.
* **Relational Databases and SQL:** Querying, manipulating, and managing data in relational databases.
* **Data Storytelling:** Communicating data insights effectively through visualizations and narratives.
