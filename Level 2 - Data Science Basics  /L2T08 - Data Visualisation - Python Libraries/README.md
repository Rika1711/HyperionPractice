## Compulsory Task 1: Data Visualization with Cars93 Dataset

This task focuses on generating various types of plots from the `Cars93.csv` dataset and interpreting the visualizations to answer specific questions.

### Instructions:

* Open the Jupyter notebook named `data_viz_task.ipynb`.
* Generate the required graphs within the notebook.
* Answer the accompanying questions in the markdown cells provided in the notebook.

### Requirements:

1.  **Box Plot:**
    * Generate a box plot for the 'revs per mile' for the Audi, Hyundai, Suzuki, and Toyota car manufacturers.
    * **Question:** Which of these manufacturers has the car with the highest revs per mile?

2.  **Histograms (Overlayed):**
    * Generate a histogram of 'MPG in the city'.
    * On the same axis, show a histogram of 'MPG on the highway'.
    * **Question:** Is it generally more fuel efficient to drive in the city or on the highway?

3.  **Line Plot:**
    * Generate a line plot showing the relationship between 'Wheelbase' and 'turning circle'.
    * **Question:** What is this relationship? What happens when the wheelbase gets larger?

4.  **Bar Plot:**
    * Generate a bar plot showing the mean 'Horsepower' for each car 'Type' (Small, Midsize, etc.).
    * **Question:** Does a larger car mean more horsepower?
