## Level 2 | Data Science Fundamentals

This section focuses on the foundational concepts and tools essential for data science. It showcases my journey in learning how to:

* **Handle Data Sources:** Understanding and interacting with various data sources.
* **Work with Databases and SQL:** Utilizing SQL for data querying, manipulation, and management within database systems.
* **Leverage Python Packages for Data Science:** Demonstrating proficiency in key libraries such as Pandas for data manipulation and analysis, and potentially others for specific tasks.
* **Understand Datasets and DataFrames:** Working effectively with tabular data structures for analysis.
* **Perform Data Visualisation:** Creating insightful visualisations using both Tableau and Python libraries (e.g., Matplotlib, Seaborn) to explore and communicate data.
* **Execute Data Cleaning and Preprocessing:** Applying techniques to handle missing values, outliers, and inconsistencies to prepare data for analysis.
* **Apply Statistical Concepts:** Utilizing fundamental statistical principles for data exploration and inference.
* **Understand Machine Learning - Supervised Learning:** Grasping the basics of supervised learning algorithms and their applications.

The **Capstone Project** in this section involved a practical application of these skills to **analyze data using a multiple linear regression model**. This project demonstrates my ability to build and interpret a predictive model based on multiple independent variables.
