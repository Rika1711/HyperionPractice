# Python Error Tasks

This project involves identifying, correcting, and creating Python programs with specific error types.

## Project Structure

* `errors.py`: A Python file containing code with errors to be corrected.
* `errors2.py`: A Python file containing code with errors to be corrected.
* `logic.py`: A Python file to be created, containing a program with a logical error.
* `optional_task.py`: A Python file to be created, containing a program with two compilation errors, a runtime error, and a logical error.

## Compulsory Task 1: `errors.py` and `errors2.py`

* Attempt to run the programs. You will encounter various errors.
* Fix the errors and run the programs.
* Add a `#` comment on each corrected line, indicating the error type (compilation, runtime, or logical) and a brief explanation.
* Save the corrected files.

## Compulsory Task 2: `logic.py`

* Create a new Python file named `logic.py`.
* Write a program that demonstrates a logical error.

## Optional Bonus Task: `optional_task.py`

* Create a new Python file named `optional_task.py`.
* Write a program containing:
    * Two compilation errors
    * One runtime error
    * One logical error
* Add comments next to each error explaining the error type and reason.
