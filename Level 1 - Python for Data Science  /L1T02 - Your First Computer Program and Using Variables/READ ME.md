# Python Compulsory Tasks

This project contains three Python programs that perform basic input/output and data type conversion.

## Project Structure

* `hello_world.py`: Python program to take user's name and age as input and print them, along with "Hello World!".
* `details.py`: Python program to take user's name, age, house number, and street name as input and print a formatted sentence.
* `conversion.py`: Python program to declare variables of different types, convert them to other types, and print the converted values.

## Compulsory Task 1: `hello_world.py`

This program takes the user's name and age as input, and then prints those values, followed by "HelloWorld!".

###   Code Description

1.  Prompts the user to enter their name using the `input()` function.
2.  Stores the entered name in a variable.
3.  Prints the user's name.
4.  Prompts the user to enter their age using the `input()` function.
5.  Stores the entered age in a variable.
6.  Prints the user's age.
7.  Prints the string "HelloWorld!" on a new line.

## Compulsory Task 2: `details.py`

This program takes the user's name, age, house number, and street name as input, and prints all the information in a single sentence.

###   Code Description

1.  Prompts the user to enter their name using the `input()` function.
2.  Prompts the user to enter their age using the `input()` function.
3.  Prompts the user to enter their house number using the `input()` function.
4.  Prompts the user to enter their street name using the `input()` function.
5.  Prints a formatted sentence containing all the entered details.

## Compulsory Task 3: `conversion.py`

This program declares variables of different data types (float, integer, and string), converts them to other data types, and prints the converted values.

###   Code Description

1.  Declares the following variables:
    * `num1` = 99.23 (float)
    * `num2` = 23 (integer)
    * `num3` = 150 (integer)
    * `string1` = "100" (string)
2.  Converts the variables as follows:
    * `num1` is converted to an integer using `int()`.
    * `num2` is converted to a float using `float()`.
    * `num3` is converted to a string using `str()`.
    * `string1` is converted to an integer using `int()`.
3.  Prints all the converted variables on separate lines.

## How to Run the Programs

1.  Ensure you have Python installed.
2.  Save the Python files (`hello_world.py`, `details.py`, `conversion.py`).
3.  Open a command prompt or terminal.
4.  Navigate to the directory where you saved the files using the `cd` command.
5.  Run each program using the `python` command:
    * For example: `python hello_world.py`
