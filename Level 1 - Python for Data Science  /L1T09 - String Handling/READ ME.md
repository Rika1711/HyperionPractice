# Python: `alternative.py`

This program reads in a string and modifies the case of its characters and words in an alternating fashion.

## Code Description

1.  Creates a new Python file named `alternative.py`.
2.  **Part 1: Alternate Characters**
    * Reads a string from the user.
    * Iterates through the string, using the index to determine whether to convert each character to uppercase or lowercase.
    * Constructs a new string with the modified characters.
    * Prints the new string.
3.  **Part 2: Alternate Words**
    * Splits the input string into a list of words using the `split()` method.
    * Iterates through the list of words, using the index to determine whether to convert each word to uppercase or lowercase.
    * Constructs a new string by joining the modified words with spaces using the `join()` method.
    * Prints the new string.

## How to Run the Program

1.  Ensure you have Python installed.
2.  Save the Python file as `alternative.py`.
3.  Open a command prompt or terminal.
4.  Navigate to the directory where you saved the file using the `cd` command.
5.  Run the program using the command: `python alternative.py`
