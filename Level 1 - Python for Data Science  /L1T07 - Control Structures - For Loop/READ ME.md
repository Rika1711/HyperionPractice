# Python: `pattern.py`

This program outputs a star pattern as shown below, using a single `for` loop and an `if-else` statement.

## Code Description

1.  Creates a new Python file named `pattern.py`.
2.  Uses a single `for` loop to iterate from 0 to 8 (inclusive).
3.  Inside the loop:
    * Uses an `if-else` statement to determine whether to print an increasing or decreasing number of stars.
    * If the loop counter `i` is less than 5, it prints `i + 1` stars.
    * Otherwise, it prints `9 - i` stars.
4.  The star character "*" is used to form the pattern.

 \****
 
 \*****
 
 \****
 
 \***
 
 \**
 
 \*
## How to Run the Program

1.  Ensure you have Python installed.
2.  Save the Python file as `pattern.py`.
3.  Open a command prompt or terminal.
4.  Navigate to the directory where you saved the file using the `cd` command.
5.  Run the program using the command: `python pattern.py`
