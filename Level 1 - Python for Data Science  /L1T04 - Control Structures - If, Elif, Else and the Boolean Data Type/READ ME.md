# Python Compulsory Task 1: `full_name.py`

This program validates that a user inputs at least two names when asked to enter their full name.

## Code Description

1.  Creates a new Python file named `full_name.py`.
2.  Prompts the user to enter their full name using the `input()` function.
3.  Performs the following validations on the user's input:
    * Checks if the user has entered anything (empty string).
    * Checks if the user has entered less than 4 characters.
    * Checks if the user has entered more than 25 characters.
4.  Displays an appropriate error message based on the validation checks:
    * "You haven't entered anything. Please enter your full name."
    * "You have entered less than 4 characters. Please make sure that you have entered your name and surname."
    * "You have entered more than 25 characters. Please make sure that you have only entered your full name."
5.  If the input is valid, displays the message: "Thank you for entering your name."

## How to Run the Program

1.  Ensure you have Python installed.
2.  Save the Python file as `full_name.py`.
3.  Open a command prompt or terminal.
4.  Navigate to the directory where you saved the file using the `cd` command.
5.  Run the program using the command: `python full_name.py`
